# Number Guessing Game — Java

## About
This project is a console-based Number Guessing Game developed in Java as part of the Oasis Infobyte Java Development Internship.

## Objective
The objective is to guess a randomly generated number within a limited number of attempts.

## Features
- Random number generation
- Difficulty levels
- Too High and Too Low hints
- Limited attempts
- Win and loss messages
- Play again option
- Score tracking

## Technologies Used
- Java
- Scanner
- Random
- Loops and conditional statements

## How to Run
1. Install the Java JDK.
2. Open Command Prompt in the folder containing `NumberGuessingGame.java`.
3. Compile the program:

   `javac NumberGuessingGame.java`

4. Run the program:

   `java NumberGuessingGame`
